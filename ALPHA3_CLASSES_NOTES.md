Session 2026-10-08. Source: `docs/Vagabond - Core Rulebook v3 Alpha 3 [Interactive PDF].pdf` (printed pp. 33–67), text-extracted with PyMuPDF and diffed per feature against `packs/_source/classes` (description, Class Features table with Spells / Mana / Cast Max, every level feature, Training / Key Stat / Starting Pack lines) plus the Active Effects behind each feature. **All 18 classes were checked, not only the ones `ALPHA3_REVIEW.md` lists.** Nothing is committed. You still run `npm run pack` (**classes** and **perks**).

## Do this first

1. `npm run pack` (classes, perks, ancestries).
2. Reload the world as GM. Migrations run once (in this order): the older class migrations → `alpha3ClassesMigrated` (class items; per-effect on/off choices kept by effect name) → `alpha3ClassPerksMigrated` (Dusted Knuckle, Quick Draw) → `alpha3AncestriesMigrated` (Human Knack → Aptitude; needs the ancestries pack too). If a migration did nothing the pack was not rebuilt (they abort without setting their guard).
3. Walk the test list at the bottom.
